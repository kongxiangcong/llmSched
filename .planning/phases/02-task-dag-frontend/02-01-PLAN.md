# Plan 02-01: TaskDAG IR Schema

## Objective

Create the TaskDAG intermediate representation schema in `ir/task_dag.py`. This defines the data structures that represent task-unit dependency DAGs: `TaskInput`, `TaskOutput`, `TaskNode`, and `TaskDAG`. These types are the contract between the frontend builder (Plan 02-02) and the scheduler (Phase 3).

Purpose: Establish the type system for execution-ready task graphs before any builder logic is written.
Output: `src/llm_sched/ir/task_dag.py` with exported Pydantic v2 models.

## must_haves

- `TaskInput` has `source_task_id: str` and `tensor_name: str` fields
- `TaskOutput` has `tensor_name: str` and `shape: list[int]` fields
- `TaskNode` has `task_id`, `macro_op`, `inputs: list[TaskInput]`, `outputs: list[TaskOutput]`, `attrs`, and `audit_ref`
- `TaskDAG` has `ir_version`, `graph_id`, `nodes: list[TaskNode]`, and `output_tasks: list[str]`
- All models use `ConfigDict(extra="forbid")`
- `TaskDAG` validates that `task_id`s are unique
- `TaskDAG` has a derived `edges` property returning adjacency list
- `ir/__init__.py` exports `TaskDAG`, `TaskNode`, `TaskInput`, `TaskOutput`
- File passes `python -m py_compile`

Create `src/llm_sched/ir/task_dag.py` with the following exact content:

1. Imports: `from __future__ import annotations`, `from typing import Any`, `from pydantic import BaseModel, ConfigDict, Field, model_validator`
2. Import `AuditRef` from `llm_sched.ir.common`

3. Define `TaskInput` class (BaseModel):
   - `model_config = ConfigDict(extra="forbid")`
   - `source_task_id: str` — the task that produces this input tensor
   - `tensor_name: str` — the name of the tensor being consumed

4. Define `TaskOutput` class (BaseModel):
   - `model_config = ConfigDict(extra="forbid")`
   - `tensor_name: str` — the name of the tensor produced
   - `shape: list[int] = Field(default_factory=list)` — shape of the output tensor

5. Define `TaskNode` class (BaseModel):
   - `model_config = ConfigDict(extra="forbid")`
   - `task_id: str` — unique identifier for this task
   - `macro_op: str` — macro operation type (e.g., "GEMM", "RMSNORM", "SDPA")
   - `inputs: list[TaskInput] = Field(default_factory=list)` — explicit input dependencies
   - `outputs: list[TaskOutput] = Field(default_factory=list)` — tensors produced by this task
   - `attrs: dict[str, Any] = Field(default_factory=dict)` — additional attributes
   - `audit_ref: AuditRef = Field(default_factory=AuditRef)` — traceability to source

6. Define `TaskDAG` class (BaseModel):
   - `model_config = ConfigDict(extra="forbid")`
   - `ir_version: str` — IR version string
   - `graph_id: str` — graph identifier
   - `nodes: list[TaskNode]` — list of task nodes
   - `output_tasks: list[str] = Field(default_factory=list)` — task_ids whose outputs are graph outputs
   - `@model_validator(mode="after")` method `validate_unique_task_ids` that checks all `task_id`s are unique, raises `ValueError("task ids must be unique")` if not
   - Property `edges` that returns `dict[str, list[str]]` mapping each task_id to a list of task_ids it depends on (extracted from `inputs[*].source_task_id`). Use `@property` decorator.

7. After creating the file, update `src/llm_sched/ir/__init__.py` to export the new types. The current file is nearly empty (just a docstring). Replace it with:
```python

from llm_sched.ir.task_dag import TaskDAG, TaskInput, TaskNode, TaskOutput

__all__ = ["TaskDAG", "TaskInput", "TaskNode", "TaskOutput"]
```

Note: Do NOT import from other IR modules in __init__.py unless they were already there. Only add the new TaskDAG exports.
