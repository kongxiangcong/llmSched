# Plan 02-02: Task DAG Builder — NIGIR to TaskDAG Transformation

## Objective

Implement `frontend/task_dag_builder.py` that transforms NIGIR into TaskDAG. The builder:
1. Elides layout ops (LAYOUT_FALLBACK, SHAPE_HELPER, ATTENTION_MASK_PREP) — they do not become TaskNodes
2. Rewires tensor dependencies through elided layout-op chains using tensor name rewriting
3. Maps remaining NIG nodes to TaskNodes with explicit TaskInput dependencies
4. Represents graph inputs and constants as TaskNodes with macro_op="Input" and macro_op="Constant"
5. Tracks graph outputs in TaskDAG.output_tasks

Purpose: Bridge the existing NIGIR (lowered workload graph) to the new execution-ready TaskDAG.
Output: `src/llm_sched/frontend/task_dag_builder.py` with `build_task_dag()` function and `TaskDAGBuildError` exception.

## must_haves

- `build_task_dag(nig_ir: NIGIR, graph_input_names: set[str] | None = None) -> TaskDAG` function exists and is importable
- Layout-op NIG nodes (macro_op in {"LAYOUT_FALLBACK", "SHAPE_HELPER", "ATTENTION_MASK_PREP"}) produce no TaskNodes
- Non-layout NIG nodes produce TaskNodes with matching macro_op
- Graph inputs (from NIGIR context) become TaskNodes with macro_op="Input"
- Constants/weights become TaskNodes with macro_op="Constant"
- TaskInput.source_task_id references the actual producer task, tracing through elided layout ops
- TaskDAG.output_tasks contains task_ids for graph-output-producing tasks
- `TaskDAGBuildError` exception class exists for build-time failures
- Builder is exported from `frontend/__init__.py`
- All code passes `python -m py_compile`

Create `src/llm_sched/frontend/task_dag_builder.py` with the following exact structure and behavior:

1. **Exception class** `TaskDAGBuildError(Exception)`:
   - `__init__(self, message: str, diagnostics: list[str] | None = None) -> None`
   - Store `self.message = message`, `self.diagnostics = diagnostics or []`
   - `__str__` returns `self.message`

2. **Layout op set** (module-level constant):
   ```python
   _ELIDED_MACRO_OPS = frozenset({"LAYOUT_FALLBACK", "SHAPE_HELPER", "ATTENTION_MASK_PREP"})
   ```

3. **Main function** `build_task_dag(nig_ir: NIGIR, graph_input_names: set[str] | None = None) -> TaskDAG`:

   **Step A: Build producer map from NIGIR nodes**
   - Create `nig_producer_by_tensor: dict[str, NIGNode]` mapping each tensor name to the NIGNode that produces it
   - Iterate `nig_ir.nodes`, for each node map `node.outputs[i]` -> node

   **Step B: Identify elided nodes and build tensor rewriting map**
   - `elided_node_ids: set[str]` = node_ids of nodes whose `macro_op in _ELIDED_MACRO_OPS`
   - `tensor_rewrite: dict[str, str]` = mapping from tensor name -> resolved tensor name after tracing through elided nodes
   - For each elided node, map each of its output tensor names to the resolved input tensor name:
     - If the elided node has exactly 1 input, map output -> that input (recursively resolved via `tensor_rewrite`)
     - If the elided node has 0 inputs, the output stays as-is (no rewrite)
     - If the elided node has >1 inputs, map each output to the first non-empty input (this handles cases like Concat that become elided as LayoutFallback)
   - Use `_resolve_tensor_name(tensor_name: str, tensor_rewrite: dict[str, str]) -> str` helper that follows the rewrite chain until fixed point

   **Step C: Create task nodes for non-elided NIG nodes**
   - For each NIGNode where `node.macro_op not in _ELIDED_MACRO_OPS`:
     - Generate `task_id` by replacing "nig." prefix with "task." in `node.node_id` (use `node.node_id.replace("nig.", "task.", 1)`)
     - Build `inputs: list[TaskInput]`:
       - For each input tensor name in `node.inputs`:
         - Resolve the tensor name through `tensor_rewrite` to get `resolved_tensor`
         - Look up the producer NIGNode in `nig_producer_by_tensor` for `resolved_tensor`
         - If the producer is elided, trace back through the producer chain until finding a non-elided producer:
           - Walk: `current = producer`, while `current.macro_op in _ELIDED_MACRO_OPS`:
             - Get the producer's input tensor (first non-empty input), resolve it, look up its producer
             - Repeat until non-elided producer found or no producer exists
         - If a non-elided producer is found, create `TaskInput(source_task_id=producer_task_id, tensor_name=resolved_tensor)` where `producer_task_id = producer.node_id.replace("nig.", "task.", 1)`
         - If no producer found (e.g., the tensor is a graph input not produced by any NIG node), skip this input — it will be handled by Input task nodes
     - Build `outputs: list[TaskOutput]`:
       - For each output tensor name in `node.outputs`:
         - Create `TaskOutput(tensor_name=output_name, shape=node.shape)` (use node's shape for all outputs)
     - Create `TaskNode(task_id=..., macro_op=node.macro_op, inputs=inputs, outputs=outputs, attrs=dict(node.attrs), audit_ref=node.audit_ref)`
     - Append to `task_nodes: list[TaskNode]`

   **Step D: Create Input task nodes for graph inputs**
   - Graph inputs are tensors consumed by non-elided tasks but not produced by any NIG node (including elided ones), AND are named in `graph_input_names`
   - Build `consumed_tensors: set[str]` = union of all `node.inputs` for non-elided nodes, resolved through `tensor_rewrite`
   - Build `produced_tensors: set[str]` = union of all `node.outputs` for ALL NIG nodes
   - `graph_input_tensors = (consumed_tensors - produced_tensors) & (graph_input_names or set())`
   - For each graph input tensor:
     - Look up its original consumer to get shape/dtype info (first non-elided node that consumes it)
     - Create `TaskNode(task_id=f"task.input.{_sanitize_tensor_name(tensor_name)}", macro_op="Input", inputs=[], outputs=[TaskOutput(tensor_name=tensor_name, shape=consumer_node.shape)], attrs={}, audit_ref=AuditRef())`
     - Prepend to `task_nodes` (inputs come first)
     - For every TaskInput in existing task_nodes that skipped this input (no producer found), add a TaskInput referencing this Input task's task_id

   **Step E: Create Constant task nodes for weight/initializer tensors**
   - Constants are tensors consumed by non-elided tasks that have no producing NIG node AND are NOT graph inputs.
   - `constant_tensors = (consumed_tensors - produced_tensors) - (graph_input_names or set())`
   - For each constant tensor:
     - Find the first non-elided consumer to infer shape
     - Create `TaskNode(task_id=f"task.const.{_sanitize_tensor_name(tensor_name)}", macro_op="Constant", inputs=[], outputs=[TaskOutput(tensor_name=tensor_name, shape=consumer_node.shape)], attrs={}, audit_ref=AuditRef())`
     - Insert after Input tasks, before compute tasks
     - Wire all TaskInputs that reference this tensor to point to the Constant task

   **Step F: Build output_tasks**
   - The NIGIR does not explicitly track graph outputs. We infer them:
   - `all_task_output_tensors = set(output.tensor_name for task in task_nodes for output in task.outputs)`
   - `all_task_input_tensors = set(input.tensor_name for task in task_nodes for input in task.inputs)`
   - `graph_output_tensors = all_task_output_tensors - all_task_input_tensors` (tensors produced but never consumed)
   - For each graph output tensor, find the task that produces it, add its task_id to `output_tasks`

   **Step G: Assemble TaskDAG**
   - Return `TaskDAG(ir_version=nig_ir.ir_version, graph_id=nig_ir.graph_id, nodes=task_nodes, output_tasks=output_tasks)`

4. **Helper functions**:
   ```python
   def _resolve_tensor_name(tensor_name: str, tensor_rewrite: dict[str, str]) -> str:
       current = tensor_name
       while current in tensor_rewrite:
           current = tensor_rewrite[current]
       return current
   
   def _sanitize_tensor_name(name: str) -> str:
       import re
       return re.sub(r"[^A-Za-z0-9_]+", "_", name).strip("_")
   
   def _find_non_elided_producer(
       tensor_name: str,
       nig_producer_by_tensor: dict[str, NIGNode],
       elided_node_ids: set[str],
       visited: set[str] | None = None,
   ) -> NIGNode | None:
       """Trace back through elided nodes to find the real producer."""
       if visited is None:
           visited = set()
       if tensor_name in visited:
           return None
       visited.add(tensor_name)
       producer = nig_producer_by_tensor.get(tensor_name)
       if producer is None:
           return None
       if producer.node_id not in elided_node_ids:
           return producer
       # Producer is elided; trace through its inputs
       for input_name in producer.inputs:
           if not input_name:
               continue
           result = _find_non_elided_producer(input_name, nig_producer_by_tensor, elided_node_ids, visited)
           if result is not None:
               return result
       return None
   ```
